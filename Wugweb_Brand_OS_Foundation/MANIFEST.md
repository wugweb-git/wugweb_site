# Wugweb Brand OS Manifest

## Purpose

This repository is the operating system for Wugweb visual work: campaign collateral, product storytelling, editorial content, presentations, and AI-assisted imagery.

## Canonical order

1. `01_FOUNDATION/` explains purpose and principles.
2. `02_VISUAL_SYSTEM/` defines the visual language.
3. `04_AI_PROMPT_ENGINE/` turns a concept into a production brief.
4. `09_VALIDATION/` decides whether an output is approved.

## Source hierarchy

Approved decisions override patterns. Patterns override observations. Observations must be backed by reference evidence. One attractive reference never becomes a universal rule.

## Production loop

Reference → Observation → Pattern → Principle → Concept Canvas → Formula → Artwork → Validation → Changelog.

Every asset should make a complex idea tangible through a singular metaphor, deliberate editorial composition, a limited palette, and meaningful product/human interaction.
