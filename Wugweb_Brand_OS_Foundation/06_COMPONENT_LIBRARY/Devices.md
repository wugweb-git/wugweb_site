# Devices

## Operational guidance

Use a phone, tablet, or browser frame only to show an actual interaction: search, route, preference, recommendation, profile, or selection. Keep it credible, rounded, naturally angled, and subordinate to the hero metaphor. One device is normally enough.

## Purpose
Define how Devices should be used within the Wugweb Brand OS.

## Design Principles
- Support the visual narrative.
- Keep an editorial composition.
- Use only when meaningful.
