# Geometry

## Operational guidance

Use one oversized circle, rounded field, arc, or quarter-circle as the anchor. Supporting geometry is smaller and quieter. It should frame, crop, or direct attention rather than compete with the hero.

## Purpose
Define how Geometry should be used within the Wugweb Brand OS.

## Design Principles
- Support the visual narrative.
- Keep an editorial composition.
- Use only when meaningful.
