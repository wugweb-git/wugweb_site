# Composition

## Operational guidance

Use asymmetrical editorial balance. Build around one large anchor occupying roughly 30–60% of the canvas. Place the hero object or active monochrome person in relation to it; allow at most three supporting objects or UI modules.

Layer deliberately: background field → anchor → photograph/object → realistic UI → one restrained accent. Crop boldly at edges and retain true negative space. Avoid centred symmetry, scattered floating components, and equal visual weight everywhere.

Use editorial, asymmetrical layouts with one dominant focal element and generous whitespace.
