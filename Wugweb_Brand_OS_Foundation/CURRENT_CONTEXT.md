## Audit update — 2026-07-26

The current project-source audit confirms that Wugweb has both a restrained editorial mode and a richer campaign-collage mode. Neither cancels the other. Choose the mode from the content objective and format before selecting components.

The exact brand token source has not yet been attached to this repository. The palette names and role rules are operational guidance; any hex value must be verified against an owned Figma file or approved brand source before being treated as canonical.

Historical system maps, dot fields, connector lines, broad secondary colours, and texture are valid reference evidence, but are not default production rules. Use them only where they make the central concept clearer.
