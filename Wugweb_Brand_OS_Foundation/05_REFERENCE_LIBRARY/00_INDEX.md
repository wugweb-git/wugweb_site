# Reference Library

## Operating rule

References are evidence, not instructions to copy. Record source, date, ownership/rights, repeated observation, confidence, and the pattern or decision affected. The current Brand OS decision log wins conflicts between historical and current work.

Master index for all evidence sources and analyses.
