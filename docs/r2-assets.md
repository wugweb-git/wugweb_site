## Path mapping (canonical)

| Layer | Pattern | Example |
|---|---|---|
| Local disk | `public/assets/<path>` | `public/assets/logos/nike.svg` |
| Site URL | `/assets/<path>` | `/assets/logos/nike.svg` |
| R2 object key | `assets/<path>` | `assets/logos/nike.svg` |
| R2 public URL | `{PUBLIC_R2_ASSETS_BASE}/assets/<path>` | `https://pub-….r2.dev/assets/logos/nike.svg` |

Keys mirror site paths **without** the leading slash. Do not invent a second prefix (`media/`, `static/`, etc.) unless migrating with an explicit manifest.

## Upload

```bash
# Requires CLOUDFLARE_API_TOKEN in env
DRY_RUN=1 node scripts/upload-assets-to-r2.mjs
node scripts/upload-assets-to-r2.mjs
```

Script aborts if upload would exceed soft ceilings (9.5 GiB storage or 100k Class A puts).

## Rule 2 — R2 MUST NOT EXCEED FREE TIER

Hard stop. Never implement or run anything that would push R2 past free allowances.

| Metric | Free monthly | Soft ceiling (this repo) |
|---|---|---|
| Storage | 10 GB | Stay under **9.5 GiB** used |
| Class A (writes) | 1M ops | Soft abort above **100k** puts in one upload job |
| Class B (reads) | 10M ops | Prefer Cache / custom domain later; avoid listing storms |
| Egress | Free | — |
| Storage class | Standard | **Never** Infrequent Access on free |

Also:

- One media bucket (`wugweb-assets`) unless the user explicitly asks for another.
- No multipart re-uploads of the whole tree without checking Class A remaining.
- `r2.dev` is for development/public read; production custom domain is optional and must stay free-tier-safe.
- Prefer Cloudflare Cache in front of a custom domain before burning Class B quota.

See also: `.cursor/rules/free-tier-limits.mdc` (Rule 1 + Rule 2).
