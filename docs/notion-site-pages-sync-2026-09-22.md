**Asset tracking check — both images are untracked:**

- Notion Asset Registry (380 rows): 0 matches on File Name / Source URL / Relative Path for either image. Zero rows tagged `Asset Group = "Framer"` exist at all. The only "Homepage"-owner rows are 5 MP4 overview videos — no images.
- All 14 `singletonPage` documents in Sanity have `ogImage` = null. The schema field exists but has never been used — every page silently falls back to the hardcoded, wrong-size `og-default.png` in `BaseLayout`.

Replace `public/brand/og-default.png` with this file (or a designed replacement — Vedanshu's call whether to keep Framer's original or swap it) — either way, code execution (Sanity/R2 upload + BaseLayout reference) is Claude Code's job, not mine.
