## Rules

1. **Always use tokens** — never hardcode color/font/spacing/radius/opacity/shadow/blur/z-index.
2. **Breakpoints:** use literal pixel values in `@media` (tokens are documentation-only).
3. **Buttons** = `--radius-sm` (8px) · **chips/tags/pills** = `--radius-full`.
4. **Yellow is a brand accent, not a primary UI color** — max ~10% per page. Primary
   interface stays grey / ash / black.
5. **Animations go through GSAP** (`src/lib/scroll-animations.ts`) — `[data-reveal]`
   / `[data-scroll]` / `data-reveal-delay`. No `motion` imports.
6. **Service panel order** alternates warm/cool so similar colors are never adjacent:
   01 Strategy → 02 Engineering → 03 Brand → 04 Growth → 05 Operations → 06 Experience.
7. **Mobile-first** — design/build for mobile, enhance up. Mobile menu caps at `100dvh`
   with a single scroll container.

  H1 700 / H2–H4 600 / body 400 / labels 500). S1 still authoritative for colours.

## Unresolved conflicts (from Framer export audit)

- **C-9** — Framer breakpoint tiers read backwards (interpretation applied, high confidence).
- **C-10** — H4 breakpoint values inverted (typo in design file).
- **C-11** — Neutral 4 and Neutral 5 are the same colour (`#A3A3A3`).
- **C-12** — Neutral 6's dark value (`#444444`) collides with Neutral 7.
- **C-13** — 33 of 66 Framer colours are `/misc/` template junk — do not build with.
- **C-14** — Framer vs Kits neutral numbering offset by one (S1 adopted).
- **C-8** — Framer export `hex` fields all read `#000000` (use `rgba`).
