### The rule behind it

- Media may be shown at any size as long as the original aspect ratio is kept. No stretching, no squashing.
- Resizing and masks are done on the page, in CSS only, never by making a new file.
- A mask must not hide the part of a screen that proves the claim.
- A file shown above its natural size is flagged, not banned.
- If the palette image is one of a Styles pair, the pair stays 50:50 at its own ratio.
- If the palette's values are legible in the file, the colours can be drawn on the page as HTML swatches from the read hex values. That is sharp at any size and needs no file.

### If nothing existing fits

A new image is made only when nothing existing fits, one file at a time, on your yes for that file, and only for a form such as a deck or a share image. It is never used as evidence inside the case study.
