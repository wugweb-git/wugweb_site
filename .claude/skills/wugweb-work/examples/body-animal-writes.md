# Example: Animal Writes, Body Content v2 skeleton (stats-led, multi-workstream)

A skeleton for a case study where Wugweb ran several workstreams in one engagement and the story is carried by numbers. Every fact the owner has not supplied is an `OWNER INPUT` marker. No number is invented; "unvalidated" is a complete answer to any marker.

Sources to read before filling it: the Animal Writes hub, Growth and Campaign Content Standard pages in Notion, and the client record (Media, Non-Profit). The Campaign Content Standard v1.0 is the rigour bar for this skill: taxonomy defined once, canonical order, conditional sections hidden when empty, evidence-led metrics with value, source, as-of date and threshold.

## How to use the skeleton

1. Replace each marker with the owner's fact, or delete the line.
2. A Results line needs all four parts. A number without a source moves to the owner questions.
3. Keep one chapter per workstream that has its own proof. Drop a workstream chapter with no proof rather than filling it with adjectives.
4. Charts are drawn from the Results lines as HTML or SVG on the page. No chart image files.

## Owner questions this skeleton raises

1. Which workstreams did Wugweb run, and which were done by others?
2. For each number: the value, what it measures, the period, the baseline or benchmark, the source and the as-of date.
3. Which screens, reports or posts prove each workstream?
4. Live URL, and any Behance, Dribbble or award links.
5. A quote from a named person, if one exists.
