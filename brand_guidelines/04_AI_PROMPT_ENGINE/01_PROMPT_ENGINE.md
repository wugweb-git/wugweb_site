# Prompt Engine

## Operational guidance

Prompt last. First complete a concept canvas: core insight, visual metaphor, hero object, human action, realistic supporting UI, anchor, palette, composition, and exclusions.

Prompt order: subject and metaphor → interaction → editorial-collage construction → limited palette/rounded geometry/monochrome treatment → output crop → negative prompts. If a result fails, revise the concept canvas before adding adjectives.

Framework for generating Wugweb-aligned visuals and content.
