# Artwork Pipeline

## Workflow

1. Complete concept canvas.
2. Select a metaphor not recently overused.
3. Draft one-anchor composition.
4. Generate or design directions.
5. Remove excess UI, lines, and decoration.
6. Check plausibility of interaction and UI.
7. Score with `09_VALIDATION/Scoring.md`.
8. Record a new observation if the work teaches the system something.

Research → Reasoning → Prompt → Generate → Review → Refine.
