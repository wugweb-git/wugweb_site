# Visual Prompts

## Use cases

For AI-native marketing, show an adaptive journey, selected signal, personalised product moment, or human-directed orchestration. For strategy, show a map, puzzle, assembled module, or route. For research, show search, magnification, selection, or a discovered object.

Always choose a new metaphor and hero object before reusing a prior visual recipe.

Prompt structures for graphics, social posts, presentations, and hero images.
