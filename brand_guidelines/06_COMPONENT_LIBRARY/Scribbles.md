# Scribbles

## Operational guidance

Use a scribble, marker line, or tiny dotted field only as a single human accent. Never use multiple scribbles, confetti, or “creative” marks to hide poor hierarchy.

## Purpose
Define how Scribbles should be used within the Wugweb Brand OS.

## Design Principles
- Support the visual narrative.
- Keep an editorial composition.
- Use only when meaningful.
