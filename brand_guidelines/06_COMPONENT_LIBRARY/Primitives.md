# Primitives

## Operational guidance

The reusable primitive set is human/hand, hero object, rounded card, credible UI, circle/arc, colour field, route/ribbon, and optional editorial accent. Use three to six at once, not all of them.

## Purpose
Define how Primitives should be used within the Wugweb Brand OS.

## Design Principles
- Support the visual narrative.
- Keep an editorial composition.
- Use only when meaningful.
