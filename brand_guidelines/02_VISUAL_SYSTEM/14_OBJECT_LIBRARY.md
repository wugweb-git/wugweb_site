# Object Library

## Operational guidance

Prefer tangible hero objects: phone, compass, map, folder, notebook, puzzle, report, package, paper tab, magnifier, camera, card, or modular block. Objects make strategic ideas felt and remembered.

Select one whose behaviour supports the narrative. Avoid prop piles, generic light bulbs, gears, rockets, and floating technology icons.

Hands, laptops, phones, documents, product artifacts.
