# Typography

## Operational guidance

Typography is an editorial graphic object: bold, clean, high-contrast sans-serif type at decisive scale with generous margins. Type can lead posters, covers, and presentation dividers; it should not rescue a hero visual that lacks a metaphor.

Keep in-art text to a strong phrase, poster fragment, or purposeful card. Avoid paragraphs, tiny labels, decorative fonts, and generated-image typography that must be read exactly.

Typography should support hierarchy, never dominate.
