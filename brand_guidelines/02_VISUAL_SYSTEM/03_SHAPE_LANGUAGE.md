# Shape Language

## Operational guidance

Default to circles, arcs, quarter-circles, pills, rounded rectangles, and softly rounded cards. Geometry frames a concept, directs attention, separates layers, or creates a conceptual stage.

Use one dominant form and quieter supporting shapes. Avoid sharp polygons, hexagon patterns, starbursts, confetti, random blobs, and decorative frameworks. Visible grids and connector lines are conditional tools for actual system-map concepts, not ambient tech texture.

Circle = Ecosystem
Rectangle = Capability
Arrow = Transformation
Grid = Architecture
