# Layout Patterns

## Operational guidance

Use an anchor + interaction, route, builder, signal, or editorial-statement pattern. Vary crop, hero object, and negative-space placement between assets.

Do not repeat a profile-card-and-phone layout across unrelated topics simply because it was previously successful. System consistency comes from visual language, not a repeated template.

Hero-left, hero-right, split-grid, radial, stacked cards.
