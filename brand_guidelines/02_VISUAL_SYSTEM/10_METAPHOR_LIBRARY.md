# Metaphor Library

## Operational guidance

Choose a metaphor before choosing components. Navigation uses maps, compasses, routes, and markers. Discovery uses search, magnification, folders, and selection. Construction uses blocks, cards, modules, and hands. Intelligence uses recommendations, knowledge cards, and informed human action.

The canonical entries live in `07_METAPHOR_LIBRARY/`. Never use robots, brains, circuitry, or holograms as shortcuts for AI.

Signals, bridges, ecosystems, orchestration, blueprints.
